# WebApp: план реализации

Идеи берутся из видео «Финансовая грамотность за 90 минут: бюджет, долги, подушка и накопления».
(Транскрипт видео недоступен — опираемся на заголовок/темы; список идей уточнить после просмотра.)

## Архитектура (FSD) — `webapp/`
`app` (провайдеры, стили) → `pages` → `widgets` → `features` → `entities` → `shared`.
Импорт только вниз по слоям, снаружи — только через `index.ts` слайса. Стек: Vite + React + TS.

## Этапы
1. **Каркас (готово)** — 4 вкладки на моковых данных: Обзор, Бюджет (50/30/20), Долги (лавина/снежный ком),
   Подушка (месяцы расходов). Кнопка `📱 WebApp` в главном меню бота (нужен `WEBAPP_URL`, https).
2. **API бота (готово)** — HTTP-сервер в боте (`/api/*`), проверка `initData` (HMAC по BOT_TOKEN), все запросы
   с `WHERE user_id=$1` из проверенного initData. Заменить `MOCK_*` в entities на запросы.
3. **Долги (готово: CRUD, срок погашения, переплата, сравнение стратегий)** — таблица `debts` (миграция идемпотентная), CRUD, расчёт срока погашения и переплаты.
4. **Подушка и накопления (готово)** — связать с `goals`, прогноз «через сколько месяцев цель».
5. **Бюджет** — лимиты по категориям из `budget`, редактирование в вебе, графики расходов.
6. **Полировка** — тема Telegram, MainButton/BackButton, a11y, тесты чистой логики (vitest в webapp).
7. **Выкладка** — статический хостинг https (webapp/dist), `WEBAPP_URL` в `.env`, чек-лист в DEPLOY.md.
