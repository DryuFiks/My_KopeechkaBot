# 💰 My Kopeechka Bot

**Personal finance Telegram bot** для учёта доходов и расходов, управления регулярными платежами, конвертации валют и анализа личных финансов.

Проект разрабатывается на **Node.js, TypeScript, grammY и PostgreSQL**. Основная цель — создать удобного Telegram-бота, который поможет вести личный бюджет прямо в чате, без необходимости использовать отдельные приложения или таблицы.

> 🚧 Проект находится в активной разработке. Функциональность будет добавляться поэтапно, начиная с минимально жизнеспособной версии (MVP).

## ✨ Возможности

* Анализ расходов по категориям.

## 🏗️ Архитектура проекта

Проект строится с разделением ответственности между обработчиками Telegram-команд, бизнес-логикой и слоем работы с базой данных.

Основные компоненты:

1. **Bot layer** — обработка команд, сообщений и callback-запросов Telegram.
2. **Service layer** — бизнес-логика финансовых операций.
3. **Repository layer** — запросы к PostgreSQL.
4. **Database layer** — схема данных, подключения и миграции.
5. **Utilities** — форматирование сумм, валидация и вспомогательные функции.
6. **Configuration** — загрузка и проверка настроек приложения.

Такое разделение позволит развивать проект без необходимости размещать всю логику в одном файле.

## 🗄️ Структура базы данных

Основные сущности, которые планируется использовать:

### `users`

Информация о пользователях Telegram.

| Поле          | Описание                 |
| ------------- | ------------------------ |
| `id`          | Внутренний идентификатор |
| `telegram_id` | Уникальный Telegram ID   |
| `created_at`  | Дата создания записи     |

### `transactions`

Финансовые операции пользователя.

| Поле          | Описание               |
| ------------- | ---------------------- |
| `id`          | Идентификатор операции |
| `user_id`     | Владелец операции      |
| `type`        | Доход или расход       |
| `amount`      | Сумма операции         |
| `currency`    | Валюта                 |
| `category_id` | Категория              |
| `description` | Комментарий            |
| `created_at`  | Дата операции          |

### `categories`

Категории доходов и расходов.

| Поле      | Описание                             |
| --------- | ------------------------------------ |
| `id`      | Идентификатор категории              |
| `user_id` | Пользователь или системная категория |
| `name`    | Название                             |
| `type`    | Тип операции                         |

### `recurring_payments`

Регулярные платежи.

| Поле              | Описание                |
| ----------------- | ----------------------- |
| `id`              | Идентификатор           |
| `user_id`         | Владелец                |
| `amount`          | Сумма                   |
| `currency`        | Валюта                  |
| `period`          | Периодичность           |
| `next_payment_at` | Дата следующего платежа |
| `is_active`       | Статус                  |

Это предварительная модель данных. Окончательная схема, ограничения, индексы и правила хранения сумм будут определены при реализации миграций.

## ⚙️ Установка и запуск

### Требования

Перед запуском необходимо установить:

* Node.js — актуальную LTS-версию.
* npm.
* PostgreSQL.
* Git.
* Telegram-бота, созданного через [@BotFather](https://t.me/BotFather).

### 1. Клонирование репозитория

```bash
git clone https://github.com/USERNAME/finance-bot.git
cd finance-bot
```

Замени `USERNAME` на имя своего GitHub-аккаунта.

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка окружения

Создай файл `.env` на основе `.env.example` и укажи необходимые значения.

```env
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:password@localhost:5432/finance_bot
NODE_ENV=development
```

Не публикуй настоящий токен Telegram-бота и пароль от базы данных.

### 4. Подготовка базы данных

Создай базу данных PostgreSQL с именем `finance_bot`.

```sql
CREATE DATABASE finance_bot;
```

Миграции базы данных должны быть выполнены перед запуском приложения. Конкретная команда будет добавлена после выбора инструмента миграций.

### 5. Запуск в режиме разработки

```bash
npm run dev
```

Команды запуска зависят от настроек `package.json` и будут окончательно определены при настройке проекта.

## 💬 Примеры использования

Предполагаемый сценарий работы с ботом:

**Добавление расхода**

```text
Пользователь: /add
Бот: Выберите тип операции
Пользователь: Расход
Бот: Введите сумму
Пользователь: 25.50
Бот: Выберите категорию
Пользователь: Еда
Бот: Расход успешно добавлен
```

**Просмотр баланса**

```text
Пользователь: /balance
Бот:
Доходы: 2500.00
Расходы: 840.50
Баланс: 1659.50
```

**Просмотр истории**

```text
Пользователь: /history
Бот:
Последние операции:

- Еда — расход 25.50
- Зарплата — доход 2500.00
- Транспорт — расход 15.00
```

Примеры показывают предполагаемый интерфейс и не означают, что эти команды уже реализованы.
